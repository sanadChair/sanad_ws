# Sanad ROS 2 Workspace (`sanad_ws`)

A ROS 2 multi-package workspace for the Sanad robot, including simulation, control, and interface packages.

## Workspace Structure

```
sanad_ws/
├── src/
│   ├── sanad_bringup/
│   ├── sanad_controller/
│   ├── sanad_description/
│   ├── sanad_interface_pkg/
│   └── ...
├── build/
├── install/
├── log/
└── README.md
```

- All packages are located in the `src/` directory.
- Build, install, and log folders are auto-generated by colcon.

## Prerequisites

- ROS 2 (Iron, Humble, or compatible)
- Gazebo (Fortress, Garden, or compatible)
- [colcon](https://colcon.readthedocs.io/en/released/) build tool
- (Optional) `teleop_twist_keyboard` for manual control

## Installation

### 1. Clone the Repository

```bash
cd ~
git clone https://github.com/sanadChair/sanad_ws.git
cd sanad_ws
```

### 2. Import Dependencies (if using vcs)

If your workspace uses a `.repos` file for dependencies:

```bash
vcs import src < sanad_ws.repos
```

### 3. Build the Workspace

```bash
colcon build --symlink-install
source install/setup.bash
```

**Tip:** To always source the workspace on new terminals:

```bash
echo "source ~/sanad_ws/install/setup.bash" >> ~/.bashrc
source ~/.bashrc
```

## Running the Packages

### 1. Gazebo Simulation

Launch the robot in Gazebo (loads the `small_house` world by default). The system supports two operational modes:

* **Localization Mode (Default):** Run the command as-is to use the existing map.
    ```bash
    ros2 launch sanad_bringup simulated_robot.launch.py
    ```

* **Mapping Mode:** Run with the `use_slam` parameter set to `true` to generate a new map.
    ```bash
    ros2 launch sanad_bringup simulated_robot.launch.py use_slam:=true
    ```

To use a different world:

```bash
ros2 launch sanad_bringup sanad_gazebo.launch.py world_name:=empty
```

### 2. Real Hardware

Launch for real robot hardware:

```bash
ros2 launch sanad_bringup real_robot.launch.py
```

### 3. Teleoperation

For real or simulated robot:

```bash
ros2 run teleop_twist_keyboard teleop_twist_keyboard -p stamped:=true
```

Or for simulation (remap topic):

```bash
ros2 run teleop_twist_keyboard teleop_twist_keyboard --ros-args -r /cmd_vel:=/sanad_controller/cmd_vel -p stamped:=true
```

## Development Notes

- Add new packages to `src/`, use `ros2 pkg create --build-type ament_cmake <pkg_name>`
- Use `colcon build --packages-select <pkg>` for fast iteration.
- For Python nodes, make scripts executable and add entry points in `setup.py`.
